# Cal in Cal out

Offline-first adaptive TDEE + nutrition + workout tracker (React Native / Expo, TypeScript).

- App: [`cal-in-cal-out/`](./cal-in-cal-out) — run `npm install && npx expo start` there.
- Architecture spec: `App_Architecture_and_Spec.md` (source).
- Workout program source data: `cal-in-cal-out/Workout_Nutrition_Tracker_Day49_Strategized.xlsx` (imported automatically on first launch).
